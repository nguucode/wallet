# Design system: gluestack-ui in the iOS / iPadOS 27 language

History: custom systems ("Clear Ledger", "Violet Sky", "Inset Grouped") → gluestack-ui default theme (2026-11-19) → **iOS / iPadOS 27 revamp on gluestack** (sếp, 2026-11-19, same day). Every screen is still built from **gluestack-ui v4** components; what changed is the values behind the tokens, the type ramp and a few component shapes, so the UI reads as a first-party iPhone/iPad app.

## Sources

- Apple Design Resources lists the **iOS 27 and iPadOS 27** UI kit (Figma, Sketch) and SF Symbols 27; the language is still **Liquid Glass**. WWDC 2026 coverage: iOS 27 refines Liquid Glass for readability (clearer/tinted options, better contrast); iPadOS 27 has edge-to-edge sidebars.
- impeccable's iOS guidance: semantic system colours, one tint, SF Pro, Body 17pt, large titles, inset grouped lists, system materials only behind bars and sheets, 44pt targets, Dark Mode first-class.

## Source of truth

- Components: generated by the gluestack CLI into `src/components/ui/<name>/`, kept as shipped. The one edited file is `gluestack-ui-provider/config.ts` (the colour values).
- Tailwind: `tailwind.config.cjs` (NativeWind preset) holds the iOS type ramp, the system font stack and the app tokens (`success`, `backdrop*`). No project CSS beyond the `@tailwind` directives.
- Viewer theme: `src/app/theme.ts` writes the tint and backdrop tokens as one stylesheet (`:root` light, `.dark` dark).

## Tokens: iOS semantic colours

gluestack token names, Apple values (grouped style):

| Token | Light | Dark | Apple role |
|---|---|---|---|
| background | 242 242 247 | 0 0 0 | systemGroupedBackground (web panel, app page) |
| card / popover | 255 255 255 | 28 28 30 | secondarySystemGroupedBackground (cells, sheets) |
| foreground | 0 0 0 | 255 255 255 | label |
| muted-foreground | 100 100 105 | 174 174 178 | secondaryLabel (one step darker than #6C6C70 for AA on the grey) |
| border / input | 198 198 200 / 209 209 214 | 56 56 58 / 72 72 74 | opaque separator / field outline |
| muted, secondary, accent | 233 233 238, 229 229 234 | 44 44 46 | fills (discs, chips, pressed rows) |
| destructive | 215 0 21 | 255 105 97 | systemRed (accessible) = cost / negative |
| success | 28 122 52 | 48 219 91 | systemGreen (darkened for AA) = gained / positive |
| primary | viewer's tint | viewer's tint | tint colour |

**Money meaning** (unchanged): green = money gained / positive (incoming, refunds, balance up, Thành công, Miễn phí, Đã thanh toán, verified, active); red = cost / negative (outgoing, fees, balance down, Không thành công, Quá hạn, over limit); pending, entered and failed (struck) amounts stay neutral. A green or red tint is allowed (sếp asked for the full rainbow); money colours stay `success` / `destructive`, not the tint.

Contrast of every pair above, every tint on every surface, and every backdrop is a unit test (`src/app/theme.test.ts`).

## Type: iOS Dynamic Type defaults

System font stack: `-apple-system, BlinkMacSystemFont, "SF Pro Text"`, then Inter (next/font, Vietnamese) elsewhere. gluestack's `Text`/`Heading` sizes resolve through these Tailwind sizes:

| Class | Size / leading | iOS style | Used for |
|---|---|---|---|
| `text-5xl` | 48/52 | display | Home balance |
| `text-4xl` | 34/41 | Large Title | page titles (`Heading 3xl`), transaction amounts |
| `text-xl` | 22/28 | Title 2 | sections (`Heading lg`) |
| `text-lg` | 20/25 | Title 3 | sub-sections (`Heading md`) |
| `text-base` | 17/23 | Body / Headline | body, row titles, menu (23 instead of 22: Vietnamese diacritics) |
| `text-sm` | 15/20 | Subheadline | meta, labels on buttons/chips/tiles, group headings |
| `text-xs` | 13/18 | Footnote | captions, status badges, tab labels, chart axis |

Group headings (`GroupLabel`) are 15 semibold secondary, sentence case; no uppercase on Vietnamese headings.

## Components (in `src/components/app-ui.tsx` unless noted)

- **Card:** inset grouped cell: card surface on the grouped background, `rounded-3xl`, no border or shadow. Lists inside are `divide-y divide-border` rows.
- **Button:** capsule (`rounded-full`); the md size is the 50pt filled button (`h-12`); all labels 15px.
- **Badge / StatusPill:** capsules in sentence case (`normal-case`); success outline green, failed solid red (dark text in dark mode), pending outline, refunded neutral.
- **Links:** tint text, no underline.
- **Sheet:** Actionsheet with 32px top corners on app, Modal with 24px corners on web, both on the card surface.
- **NavBar (app):** clear at rest; glass material (`bg-backdrop-app/75 backdrop-blur-xl` + hairline) once content scrolls under it; large title below on tab roots.
- **Tab bar (app, `Shell.tsx`):** floating Liquid Glass capsule above the home indicator (`bg-card/75 backdrop-blur-2xl`, hairline, soft shadow); current tab is a tinted pill; Scan stays the filled tint button.
- **Sidebar (web, `Shell.tsx`):** iPadOS 27 edge-to-edge sidebar on the backdrop; current item is a rounded card cell with the tint on its icon; Demo controls box is a glass card.
- **Web panel:** the 672px content column is the grouped background (`rounded-[28px]`, soft shadow) on the viewer's backdrop; cards sit on it as cells.
- **Balance card (`HomePage.tsx`):** dark in both modes: the card is a `dark` scope, so every token inside takes its dark value (text, chart, chip, tint); a radial glow of the tint sits on its own layer behind the content.
- Materials (blur) only on bars, the tab bar, the sidebar's demo box and sheets: never behind reading content.

## Viewer theme (Demo controls)

- **Màu chủ đạo:** the seven rainbow colours (Đỏ, Cam, Vàng, Lục, Lam, Chàm, Tím) as Apple's accessible system colours; default Lam (iOS blue).
- **Giao diện:** Theo hệ thống → Sáng → Tối (Tailwind `darkMode: 'class'`; gluestack's colour-mode script, inlined in `<head>` with the stored mode).
- **Nền:** Xám trung tính (systemGray5 behind the panel), Chuyển màu (tint-to-grey gradient), Đơn sắc (solid tint). The app page uses a paler cut (`backdrop-app*`) so secondary text stays AA.
- Web: box in the sidebar footer (palette popover when collapsed); app: top of the Demo controls sheet. Stored per viewer in localStorage; "Mặc định" restores Lam / system / neutral.

## Conventions kept from the gluestack audits

- Headings always pass `as` (h1 page title, h2 section, h3 sub-section); never `as` with `isTruncated` (use `truncate`).
- Notes and info boxes: Alert surface (`rounded-lg border border-border bg-card p-4`); never secondary text on a fill.
- Icons inside buttons through `Ico`, not `ButtonIcon`.
- Row actions: a Sheet on both layouts (gluestack's Menu popover cannot shift off the right edge).
- Providers: `GluestackUIProvider` in `app/layout.tsx` (SSR theme variables) and again inside `BrowserRouter` (overlays need router context).
- Web content scrolls in `#main-scroll`: use `pageScroller()`, never `window.scrollY`.
- One literal colour: `bg-white` behind QR codes and barcodes (scanning).

## Rules

1. No raw HTML elements for UI in screens: gluestack components only. An `<svg>` drawing (QR, barcode, chart) is the exception.
2. Colours only through tokens; no hex in screens. Glass/blur only where listed above.
3. Accessibility: one h1 per page (focused on route change), live regions for status and errors, labelled inputs, skip link, 44pt targets on the app layout, AA contrast in light and dark (unit-tested).
